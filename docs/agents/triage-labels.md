# Triage labels

| Canonical role | Local status | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The issue needs more information. |
| `ready-for-agent` | `ready-for-agent` | An agent can implement the issue. |
| `ready-for-human` | `ready-for-human` | The issue requires human work. |
| `wontfix` | `wontfix` | The issue will not be implemented. |

When a skill names a canonical role, use the matching local status.
